# RinaYaki

OurDeskPet 的视频字幕与实时字幕组件，可从 Desk 扩展工具打开，也可运行本目录的 `Start-RinaYaki.vbs`。

- [统一用户手册](../docs/用户手册.md)：安装、API、视频翻译、字幕导出与实时字幕。
- [独立面板指南](docs/user/README.md)。
- [开发文档](docs/README.md)与[发布构建](../docs/BUILDING.md)。

完整安装包已包含 Python 运行时和媒体工具；使用者需配置自己的模型 API。视频处理可自动完成转写、翻译和精修，再调整字幕样式导出。实时字幕采集系统声音，转写与翻译可能产生服务费用。配置保存在安装根目录的 `data/RinaYaki`。
