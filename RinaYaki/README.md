# RinaYaki

视频字幕加工与实时翻译工具，可独立运行，也可从 RinaDesk 扩展工具打开。当前桌面流程主要使用配置好的云端 API，转写和翻译会自动处理，无需手动执行各阶段。

环境准备完成后，双击 `Start-RinaYaki.vbs`。视频处理完成后可确认字幕样式并导出成片；实时翻译则把系统声音显示为字幕。主动开始处理会调用所选 API，可能产生服务费用。

- **使用软件**：[用户指南](docs/user/README.md)——首次配置、会发生什么、结果在哪里，以及中断时怎么办。
- **开发与维护**：[开发文档索引](docs/README.md)——源码安装、模型与配置、任务恢复、协议和测试。普通使用无需阅读。

`Yaki` 来自“烤肉”的“焼き（やき）”。
