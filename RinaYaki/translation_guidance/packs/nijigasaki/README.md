- 田中ちえ美 → 田中千惠美：声优正式名称。
- ちえ美 → 千惠美：声优名字简称。
- ちぇみー → 切咪：按你指定的中文爱称保留。[日文爱称来源](https://artist.cdjournal.com/a/tanaka-chiemi/934557)
- 田中 → 田中：只在确认人物后使用，不能擅自展开，更不强制改成切咪。
- 天王寺璃奈 → 天王寺璃奈：角色正式名称。
- 璃奈 → 璃奈：角色简称。
- 田中千惠美 ↔ 天王寺璃奈仅记录配音关系，不是可互换名称。

## 基础词

[terms.json](terms.json) 有 11 条：Love Live!、完整作品名、虹咲学园学园偶像同好会、虹咲学园、虹咲、ニジガク、学园偶像、学园偶像同好会、学园偶像部、同好会、偶像部。

虹咲社团原名是“虹ヶ咲学園スクールアイドル同好会”。所以“スクールアイドル同好会 → 学园偶像同好会”与“スクールアイドル部 → 学园偶像部”分开，不把部写成它的正式名称，也不把普通的部都改成同好会。

## 当前需要你验收的地方

1. 13 组中文姓名是否符合你的习惯，尤其米娅/米雅、艾玛的姓氏译法。
2. [nickname-candidates.json](nickname-candidates.json) 中的声优与角色爱称归属、希望使用的中文写法。空值表示尚未定译，不会拿声优全名填充。
3. “ニジガク → 虹咲”是否采用，还是更想保留其他圈内简称。
4. 是否扩展旧版素材：本版雪菜对应林鼓子；楠木ともり/ともりる不是林鼓子的别名。[声优交接报道](https://www.oricon.co.jp/news/2272983/embed/video/?anc=252) 后续可单独增设历史声优条目，不能为凑13人将两位合并。
5. 短称“爱、彼方、秀、田中”先要求上下文，不做全局替换。
