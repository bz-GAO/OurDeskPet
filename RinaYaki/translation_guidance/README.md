# 翻译指导文件夹

这里存放人工维护的翻译术语包，不放录音、字幕输出、缓存、API Key 或大段百科资料。

当前仅有示例包：[虹咲](packs/nijigasaki/README.md)。已接入实时翻译第二步的按会话选择，默认关闭；勾选草案试用后才使用。离线精修尚未接入。[使用说明](../docs/TRANSLATION-GUIDANCE.md)

## 组织方式

- 每个主题一个稳定目录：`packs/<pack-id>/`。一个主题可整体勾选，不必分别导入角色和声优。
- 一个目录只有一个 `pack.json` 清单；它明确区分术语数据文件和待审文件。
- 实体名称、别名、配音关系分开存储。演员—角色关系仅帮助消歧，不能作为互相替换的翻译对。
- 待审爱称不能混进已确认别名；中文译法可按用户习惯调整，不把个人偏好伪装成官方定译。
- 字段约定见 [FORMAT.md](FORMAT.md)。当前是 v1 草案；加载器仅读取选中包的 data_files，待审文件不加载。

优先编辑 JSON 数据文件；包内 README 的表格是本次验收快照，修改 JSON 后需同步表格。
