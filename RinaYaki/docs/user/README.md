# RinaYaki 用户指南

## 开始之前

已准备好运行环境时，双击项目内的 `Start-RinaYaki.vbs`。也可以从 RinaDesk 的扩展工具打开。只有源码、尚未安装环境时，请按[开发安装说明](../development/README.md)准备一次。

在“设置”中填写 API Key。默认模型与地址已预填，正常使用无需编辑 `.env` 或逐项配置内部阶段；使用不同地域或服务时，按服务方提供的信息调整。没有 Key 可查看[阿里云百炼的官方获取说明](https://help.aliyun.com/zh/model-studio/get-api-key)，获取后回到设置保存。网页登录不等于已给软件配置 Key；不要把密钥发给他人。

预览视频不会调用转写或翻译模型；主动开始视频处理或实时翻译会使用所选 API，可能产生费用。具体权限、额度与计费以服务平台为准。

## 视频翻译：提供视频，等待处理，确认导出

粘贴单个视频链接、BV 号、YouTube 视频号，或选择本地视频。预览后确认画质、保存位置、工程名及语言，开始处理即可。默认自动识别源语言，字幕为简体中文。

软件会自动准备音频、转写并翻译，按配置进行精修；不需要手动搬运文件或逐个调用 API。进度页会显示当前阶段，部分云端阶段只有状态与等待时间，没有精确百分比。

处理完成后，确认字幕字体与颜色并导出。最终观看用的字幕 MP4 放在你选定的工程文件夹顶层；字幕文件、原视频及中间记录保留在子目录，通常不需要操作。重新调整样式并使用已有处理结果导出，不需要再次调用转写和翻译模型。

默认保存位置是 RinaYaki 项目内的 `output`，可以在设置中更改。新默认值只影响新工程，不搬动已有文件；工程开始后，其位置、名称与语言固定，换语言请建新工程。

## 实时翻译：听系统声音，显示字幕

选择声音来源、语言和显示方式后开始，软件会持续识别并显示字幕。当前来源以系统声音采集为主，网页直播链接不等同于可以直接接入。

“暂停”停止接收新声音，已送出的处理结果可能稍后到达；“继续”从恢复时刻接收，不补录暂停期间的声音。关闭字幕窗口结束会话并保存记录。只有勾选录音才保存音频；仅原文模式仍使用识别服务，但不调用翻译服务。

术语包是可选项，在本次会话中选择即可，不选也能使用。它帮助统一名字与用语，不保证译文完全正确；当前离线视频流程不使用这项实时术语选择。

## 登录、关闭与出错

- 需要网站权限时，用视频页的“登录”打开 Yaki 自己的登录窗口，再重新预览；不会共用日常浏览器的登录状态。网站支持和可下载画质受站点及账号权限限制，不绕过 DRM。
- 关闭视频主窗口不等于停止已开始的后台处理。重新打开同一视频，选择已有待完成工程，可查看进度或恢复；重启电脑会停止后台任务，需要重新进入。
- 遇到错误先保留工程和中间文件，按界面提示处理。API 权限或额度不足时检查对应平台；如果提示上一次付费请求状态不明确，不要反复新建任务以免重复付费。
- 设置、密钥、网站登录和视频工程彼此分开保存。不要通过删除 `.env`、锁文件或缓存来“修复”任务，也不要把整个项目目录直接打包给他人。
