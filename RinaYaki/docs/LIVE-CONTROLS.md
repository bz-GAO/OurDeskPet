# 实时会话控制与后续个性化

开发文档：用户使用入口见[用户指南](user/README.md)。下文说明状态、时序和实现边界，不是启动前需要逐项完成的步骤。

## 已实现

- 结果窗口使用“暂停 / 继续”，不再把工具栏按钮作为退出入口。
- 暂停立即拒绝新音频帧，随后在后台停止采集和 ASR 连接；暂停期间不录音、不识别，不在恢复后补采。已进入发送流程的帧，以及暂停前的识别收尾、翻译队列仍可完成。
- 恢复建立新的采集和 ASR 连接，沿用会话目录、录音文件、字幕编号和翻译队列。录音直接拼接有效音频，不插入休息时长；新 ASR 时间戳按累计有效音频偏移。事件日志记录暂停/恢复与音频位置。
- 暂停时可滚动查看字幕。右上角关闭窗口才结束会话并完成归档；未勾选录音时不保存音频，但保留文字与会话记录。错误或到达运行时限后，结果窗口保持打开，供回看，不能继续已结束的会话。
- 显示模式收为单个菜单，仅改变显示，不更改翻译流水线。原文识别模式启动时不建立翻译客户端，也不允许在结果窗口启用译文；需要翻译请新开相应会话。
- 原文与译文采用两条解耦链路：ASR 完成一段就先显示原文，Qwen-MT 通过兼容接口流式返回后，译文按短块更新同一段。换行或后续内容到达时只重排对应行，不重建整个字幕缓冲区；用户正在回看旧字幕时不会被拉回底部。
- `qwen-mt-flash` / `qwen-mt-lite` 的增量块与 `qwen-mt-plus` / `qwen-mt-turbo` 的累计块在 provider 层统一为完整快照。会话记录保留增量事件，最终字幕与转写文件只采用完成后的译文。
- 流中断或异常结束不计为翻译成功；已显示的部分译文保留并标记“未完成”。关闭会话后不再发布译文，正在读取的网络请求在下一次文本回调或超时后结束。

## 术语能力与后续边界

实时术语包已经实现，现行检索和模型参数映射以 [TRANSLATION-GUIDANCE.md](TRANSLATION-GUIDANCE.md) 为准。下面仅保留离线复用与未来配置方向，不再将整个实时术语能力标为尚未实现。

共享配置优先存储术语、人物名称、别名、禁用译法、语言方向、适用项目与示例，而非一份不加区分的大提示词。

1. 实时侧已选取当前片段相关的少量术语及领域信息，按不同链路映射为 terms/domains 或 corpus.phrases；不把规则混入待翻译原文。
2. 离线初译可复用同一术语配置；精修侧再加入完整风格要求、上下文和正反例，统一全篇名称、语气和表达。
3. 若以后包装成“skill”，本质是可版本管理的翻译配置包，由应用加载并转换为各模型支持的请求形式；模型不会自动读取文件。会话应记录配置版本以便复现。

可编辑术语表与离线项目级复用仍需另行设计，不是用户必须预先准备的配置。规则用于表达与术语一致性，不允许补写原文没有的事实。
