# Voice module

Desk 的语音功能模块，按"说话的方向"分为两侧，互不依赖：

- `input/` —— **我们这侧的说**：用户语音 → 文字。麦克风采集 + DashScope 流式 ASR，
  当前作为 Chat 的语音输入使用。已实现。
- output 侧 —— **桌宠这侧的说**：预录制语音包回放 / 未来的克隆音色离线生成语音。
  尚未实现；落地时在本目录下新建 `output/` 子模块，不要与 input 共享状态。

两侧共用的约束：

- 不引入 Python sidecar，全部原生实现（安装器故事不破坏）。
- 付费 API 只在用户显式动作（点击）后调用，永不后台静默运行。
- 涉及的协议与选型记录见仓库 `docs/VOICE.md`。
