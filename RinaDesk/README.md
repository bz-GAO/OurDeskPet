# RinaDesk

Windows 桌面宠物，提供 Chat、设置、璃奈板与扩展工具入口。可选择夏服、冬服、Astromeda 或 A.L.A.N 像素方案；支持自定义人物、主题和粒子特效。

- **使用软件**：[用户指南](docs/user/README.md)——桌宠操作、对话保存、API 设置和扩展接入。
- **开发与维护**：[文档索引](docs/README.md)、[构建指南](docs/DEVELOPMENT.md)——源码环境、实现契约和测试。
- **项目进展**：[当前状态与后续建议](docs/STATUS.md)——开发验收与待讨论方向，不是使用前置条件。

开发技术为 Tauri 2、React、TypeScript 和 Rust。运行已构建程序不需要 Rust 或 Node；安装包仍属后续工作。

璃奈及相关设计来自 Love Live! 虹咲学园。本项目是非官方个人项目，素材来源见 [assets/README.md](assets/README.md)；来源署名不代表取得原角色或参考美术的授权。
