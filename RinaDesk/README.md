# RinaDesk

OurDeskPet 的桌面入口，提供默认像素人物、Chat、项目助手、语音、设置与扩展工具。

- [统一用户手册](../docs/用户手册.md)：安装、API、桌宠、对话及扩展使用。
- [正式安装包](https://github.com/bz-GAO/OurDeskPet/releases)：包含 Desk、Yaki、Tomo 和便携运行时。
- [开发文档](docs/README.md)与[发布构建](../docs/BUILDING.md)。

发布版仅内置一套像素人物，支持导入自有图片；语音使用服务商基础音色。程序和数据路径由 OurDeskPet 安装器管理。

开发技术为 Tauri 2、React、TypeScript 和 Rust。璃奈及相关设计来自 Love Live! 虹咲学园，本项目为非官方个人项目。署名不代表取得原角色或参考美术的授权；许可及第三方说明见仓库根目录。
