# 扩展工具与导航

设置窗口外层的“扩展工具”页面集中展示 RinaYaki 与 RinaTomo。添加工具页中的 GitHub
按钮是源码/发布入口，不是自动安装器。

RinaYaki 需要先选择完整的本地项目目录完成“接入”；已经接入时可以重新定位。视频翻译
和实时翻译共用一次接入记录。RinaTomo 已由 Desk 原生集成，卡片上的“打开”进入 QQ Bot
控制页；运行控制仍由 Tomo 自己提供。

稳定导航目标（计划用于回答后的用户点击）：`extensions.add`、`extensions.yaki.video`、
`extensions.yaki.live`、`extensions.tomo`。模型只能建议这些目标，不能自行跳转或拼接路径。
