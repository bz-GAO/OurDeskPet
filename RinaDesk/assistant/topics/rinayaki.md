# RinaYaki

RinaYaki 是独立的字幕与翻译工具，包含视频流程和实时翻译。视频流程导入 URL 或本地
视频，经过识别、翻译、字幕样式与导出；实时翻译从系统音频产生置顶字幕和会话归档。

在 Desk 中先到“扩展工具 → 添加工具”接入 RinaYaki 项目目录。接入后顶部出现“视频翻译”
和可用时的“实时翻译”。API、模型和默认项目目录由 Yaki 设置管理，密钥不会回显给 Chat。

处理任务可能调用付费 API；项目助手只解释和查看状态，不启动任务。详细恢复、缓存和
产物规则以 RinaYaki 自己的 README 与 docs 为准。

视频页支持链接、B 站 BV 号、YouTube 视频号和本地视频；先“预览”，再选可用画质，点击
“继续”创建任务。清晰度由网站适配返回，分辨率相同也可能有帧率或码率区别；锁定项需要
网站对应权限，不代表登录后一定可用。频道首页和推荐列表不等于单视频。
读取页在站点解析阶段显示活动状态，网络下载开始后显示实际百分比；本地视频复制也显示
字节进度。缓存命中时读取阶段可能很快直接完成。

视频页“登录”打开 Yaki 管理的 WebView2 窗口；Desk 复用 Yaki 的登录流程。它有自己的
持久化站点会话，不等于 Edge 日常浏览器的登录状态；重启 Yaki 不会主动清掉登录。
登录后需要重新预览以刷新权限和清晰度。网站支持取决于适配器；一个网站能播放不代表
任意网站都可导出。助手不能查看 Cookie、会员账号或自动完成登录。

设置的“实时翻译方式”可选“标准（ASR＋MT）”或“LiveTranslate”。字幕样式与输出行为
以当前原生界面、Desk 集成页和 `src/rinayaki/live/` 实现为准。视频转写默认模型已升级到
3.1；模型、计费和网站规则可能变化，不能把指南当作最新服务价格或实际账号状态。
