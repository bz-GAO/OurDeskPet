# RinaTomo

RinaTomo 是独立的 QQ Bot。Desk 的“扩展工具 → QQ Bot”页同步显示 NapCat、QQ 和服务
状态，并提供启动/暂停、关闭服务、对话功能、大模型、权限白名单与自动启动设置。

未运行控制器时点击“打开 Tomo”。登录需要二维码时，Desk 页或独立面板会显示登录信息。
白名单默认拒绝：管理员、允许私聊用户和启用群聊分别配置。大模型回复需要 Tomo 自己的
本机 API 配置，Desk Chat 的 API 不会自动写入 Tomo。

项目助手不能登录 QQ、修改白名单或启动/关闭服务；后续可以给出经过校验的页面跳转按钮，
由用户点击后进入 `extensions.tomo`。
