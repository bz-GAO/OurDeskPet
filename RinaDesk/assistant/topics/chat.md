# Chat 使用

Chat 顶部和设置 → API 配置有账户状态框，可切换 DeepSeek/阿里云百炼等已配置账户。
余额自动每 10 分钟刷新，也可点刷新图标；今日花费为本机项目启用统计后的参考价估算，
按系统日期跨天归零，同一天重启保留。金额带星号表示不完整，不是平台的完整账单。
百炼余额需要在设置 → API 配置 → 连接账务查询填写账务只读 AccessKey（不是模型 API Key）。

桌宠的聊天窗口统一称为 Chat。窗口顶部可以实时切换普通 Chat 与项目助手；两页复用
当前 API 配置和交互组件，但消息、草稿、附件与模型上下文彼此独立。

普通 Chat 以日常对话为主。项目助手用于解释三个项目、功能位置、使用方法、边界与
常见故障。项目助手默认读取已接入项目的固定简要指南，不可用时使用内置备份；设置中明确开启后，才会获得受限
的只读源码工具。设置 → Chat → 项目助手另有“允许助手提出安全设置修改”（默认关闭）。
开启后可调整记忆参数、联网开关/默认模式、等待时间或通用页开机启动；居中弹窗显示前后对比，你点击“确认修改”
才保存，下次请求生效。不能修改源码、路径、密钥、权限或 Yaki/Tomo 设置，不能运行命令或代替你确认。

联网的“自动 / 关闭 / 必须搜索”与模式切换互相独立。项目问题通常先查本地指南；只有
涉及当前版本、外部服务或用户明确要求时才需要联网。DeepSeek 官方配置直接使用同一账户的
搜索服务；其他配置使用 Tavily，已配置 Tavily 时也可作为 DeepSeek 的备用来源。

输入框左侧的文件夹按钮可附加图片和文件。文本模块支持 UTF-8、带 BOM 的 UTF-16 和受限
GB18030 回退；CSV/TSV 支持引号、多行单元格和行号。代码模块对
TypeScript/TSX、JavaScript/JSX、Python、Rust 使用 Tree-sitter AST，提取导入、符号、
语法错误和行号；同时附加多个代码文件时还会建立可能的本地模块连接。其他语言使用
启发式结构回退。工作文件模块可提取 DOCX 标题、段落和表格，以及 XLSX 工作表、日期、
合并区域、公式和缓存值；不会执行公式，也不保证提取图片、页眉页脚等所有内容。
PDF、PPTX 和扫描件暂不解析。图片与文件合计每轮最多八个；文本和代码不再使用旧的
512 KiB 限制，但文件仍有大小和模型上下文限制。新对话固定清空消息和草稿，“清空上传的文件”决定是否同时清理当前页
的内存文件库；退出桌宠会全部清理。
顶部可选“自动保存 / 不保存”，默认自动保存到本机 RinaDesk 数据目录的 Conversations 文件夹；设置 → Chat 可更改目录。
同一对话更新同一个 JSON，不为命名额外调用模型；修改目录不搬动旧文件。左侧栏的上半部是当前对话文件与
资料库，点击“引用”把已解析快照放回输入框上方；引用不会重读磁盘，文件修改后应重新上传。
下半部可加载明确选择或保存过的 RinaDesk JSON，保留对话所属模式；删除关联不删除 JSON。
普通任意 JSON 不等于可加载的对话。自动保存的对话重启后恢复列表；移除关联不删除 JSON。关闭自动保存不会删除已有文件。
目前尚无模型自动检索整个附件库的能力，发送附件会占用模型上下文。只有图片可点击预览。

稳定导航目标（尚只作为说明）：`chat`、`settings.chat`。
