# RinaDesk 文档索引

## 面向用户

日常使用统一看[用户指南](user/README.md)：桌宠操作、对话保存、API 设置与扩展。模型实现、缓存、构建、协议和开发待办不放进用户指南。

## 面向开发：维护规则

1. [当前状态与后续开发](STATUS.md)是完成度、未完成事项和优先级的唯一入口。
2. 功能专题文档描述现行行为和安全边界；修改实现时同步修改对应专题。
3. 带日期的路线图、迭代和验收文件是历史记录，不覆盖 `STATUS.md` 或现行专题文档。
4. 若文档与代码/测试不一致，代码和测试用于核对实际行为，但不代替用户要求或证明实现正确；记录差异并在下一个本地检查点前修正。
