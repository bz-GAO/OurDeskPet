# RinaDesk 用户指南

## 桌宠与璃奈板

使用已准备好的本机快捷方式启动。单击人物打开或收起小璃奈板，拖动清醒的人物可移动位置，右键切换休眠／唤醒。休眠时不能拖动；像素方案休眠会留下独立面具。当前不提供自动行走。

小板的三颗星从左到右为 Chat、最小化桌宠、退出；点击板内笑脸打开设置。最小化后可从任务栏恢复。设置大板的星星用途不同：打开扩展工具、最小化设置、只关闭设置；拖动可见边框移动面板。

## 对话与保存

在 Chat 中选择普通对话或项目助手，然后发送消息。可粘贴截图、添加支持的附件；联网搜索是独立选项。模型调用及搜索可能产生所用服务的费用。

新对话先显示本地标题，首轮完整回复后尝试异步生成更合适的标题；失败保留原题，手动重命名优先。标题生成与是否保存对话相互独立。

“自动保存”将对话保存为本机受管理文件，可从左侧目录重新打开；“不保存”不会自动落盘。默认目录是已定位 RinaDesk 项目内的 `Conversations`，可在“设置 → Chat → 对话保存位置”更改，侧栏文件夹按钮可打开保存目录。更改目录不搬动旧文件。

关闭 Chat 窗口仍保留本次程序运行中的会话。完全退出后，未保存的页面和上传文件库不会保留；程序不自动恢复上次活动页面。模型回复与助手建议需自行核对，项目助手的源码读取权限单独控制。

## 设置

| 页面 | 可以调整什么 |
| --- | --- |
| 美术 | 人物、主题、高级特效。四个内置方案不能删除；自定义只更换人物，不更换璃奈板 |
| API 配置 | 为 Chat 配置服务地址、模型和密钥，保存后启用；官方平台跳转不等于已授权 |
| Chat | 对话记忆、保存位置、联网搜索、项目助手权限等 |
| 通用 | 开机启动、运行诊断 |

账户余额、模型 API Key 与网页登录是不同配置。已有 Key 编辑时留空表示保留，不要把密钥发给他人。普通使用通过设置页操作，不需要改源码。

## 扩展工具

RinaYaki 和 RinaTomo 是独立程序，各自管理配置、账号和任务。Desk 提供入口和控制页面，不代表已替它们完成安装或 API 接入。

Yaki 从“添加工具”接入完整项目目录，移动目录后用“重新定位”；移除接入记录不删除视频工程。Tomo 从 QQ Bot 页面打开并按独立界面完成 QQ/NapCat 设置。关闭 Desk 不应被当作已停止所有独立工具或任务，请在各工具中确认状态。
