# RinaTomo 用户指南

## 开始使用

准备好 NapCat Shell、QQ NT 与 Tomo 运行环境后，双击 `Start-RinaTomo.vbs`，或从 Desk 的“扩展工具 → QQ Bot”打开。只有源码、环境尚未准备时，先按[开发安装说明](../development/README.md)配置一次。

首次打开保持离线。在设置中确认检测到的 NapCat/QQ，点击“启动”，按界面提示扫码或确认登录。登录后连接由软件自动建立，正常使用无需手填 OneBot 服务字段。若简化登录页无法完成设备确认，可打开 NapCat 完整页面继续。

## 让它回复谁、回复什么

配置管理员、允许私聊用户和启用群聊，再点击对应区域的“应用”。未放行的消息默认不回复；管理员权限较大，只添加你信任的账号。

模型回复需要启用对话功能并配置 Tomo 自己的 API；Desk Chat 的密钥不会自动共享。已放行的消息用“问：”或“问:”开头触发。模型调用可能产生费用，具体额度与价格以服务平台为准。

普通请求默认不携带完整聊天记录；显式引用近期由 Tomo 参与的消息时，可沿该分支带入有限上下文。不要把它当作永久聊天记忆。并行问题可能按完成先后回复，并非严格按提问顺序。

## 暂停与退出

- “暂停”停止回复，NapCat/QQ 可继续保持连接；再次启动恢复回复。
- “关闭服务”结束服务，并关闭由本次 Tomo 启动的 NapCat/QQ；不会接管关闭原先外部启动的 NapCat。
- 从独立快捷方式打开时，关闭主窗口即退出服务。
- 由 Desk 托管时，关闭独立面板或离开 QQ Bot 页仅隐藏界面；退出整个 Desk 或关闭服务才结束托管运行。

自动启动默认关闭，可在设置中选择是否打开面板后自动启动。不要把隐藏面板误认为已经停止回复。

## 配置与隐私

设置保存在当前 Windows 用户的数据目录，重新下载源码不会自动清除它们。不要分享真实账号、token、API Key 或登录缓存；切换电脑需重新完成配置与登录。

遇到连接或账号验证问题，先看面板状态与登录提示；开发命令、配置文件结构和排查接口不属于日常使用步骤。
